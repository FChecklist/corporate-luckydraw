# Rules of Corporate Lucky Draw
## Joining
1. Only people the Organizer invites can join. Each person joins once with an ID.
2. Joining closes at the draw time. Nobody can join after the draw starts.
3. A rehearsal has up to 10 people and no prizes.
4. A draw can have up to 100,000 people.
## The draw
1. The draw runs by itself at the published time, or the Organizer or a Host starts it by hand.
2. The Organizer sets the number of winners and the prizes before the draw.
3. The game software picks the winners using the public random beacon from drand. The same entries and the same public beacon give the same winners.
4. Only the Organizer or a Host can pause and resume the draw.
## After the draw
1. The result is shown to everyone who joined. Winners get an e-mail and a "You won" button.
2. Prizes are given by the Organizer, not by the game software.
3. A new draw like this one copies the settings only. It does not copy the people.
